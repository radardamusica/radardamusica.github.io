# Radar Belchior 80

Guia dos lançamentos dos 80 anos de Belchior (26/10/2026) e dos 50 anos do disco Alucinação (1976): o que saiu, o que vem por aí, onde ver, ir ou comprar, calendário, notas dos fãs e a lista de cada um.

No ar em https://radardamusica.github.io/

- `index.html`: o site
- `dados.json`: a lista de lançamentos, atualizada toda semana a partir da imprensa
- `config.js`: endereço e chave pública do Supabase
- `supabase.sql`: tabelas e regras das notas e listas dos fãs
